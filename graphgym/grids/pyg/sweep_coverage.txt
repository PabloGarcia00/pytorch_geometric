# span=True  → optimal coverage: only nodes active in the first AND last week of the
#              dataset window are included; late-onboarded / early-offboarded nodes dropped.

#              handles missing readings at the edges for partial-span nodes.
#
# NOTE: this flag controls node selection at dataset load time, not at process() time,
#       so no reprocessing (data.pt deletion) is needed when switching between values.
#
# alias  meaning
# span   earne_data.require_full_span
